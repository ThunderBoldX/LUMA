Розпізнавання музики

Назви треків від радіостанції визначаються без ключа. Коли станція не передає назву, LUMA може розпізнати 12 секунд ефіру через AudD.

Ключ зберігається тільки в пам’яті вкладки. Розпізнавання надсилає аудіофрагмент до AudD; запити використовують ліміт твого облікового запису.

Одноразове налаштування Discord
  1. Створи застосунок з назвою LUMA у Discord Developer Portal.
  2. Встав його Application ID у поле вище. Це публічний ID застосунку, а не токен акаунта.
  3. У розділі Rich Presence → Art Assets додай файл LUMA-Discord.png із папки програми, назви зображення luma. Цей файл також можна використати як іконку застосунку.
  4. Відкрий Discord, увімкни показ активності та натисни «Підключити» в LUMA.

Назва програми в Discord береться з Developer Portal. LUMA не створює акаунтів і не потребує пароля чи токена Discord.

Оверлеї та медіапанель

Windows і сумісні медіаоверлеї отримують назву треку, виконавця, станцію та фіолетову обкладинку LUMA через медіапанель браузера.

Оверлей для OBS

Додай «Джерело браузера» та встав адресу нижче. Рекомендований розмір: 470 × 140. Фон прозорий, дані оновлюються автоматично, поки відкрита LUMA.
