# Third-party services and runtimes

LUMA's source and original artwork are licensed under MIT. No third-party JavaScript packages or music recordings are bundled in this repository or the portable release.

- **Node.js** is required at runtime and is installed separately. Its licenses are at https://github.com/nodejs/node/blob/main/LICENSE.
- **Microsoft .NET Framework / Windows Forms** is used by the Windows launcher. Windows supplies the runtime; Microsoft Edge supplies the optional app window. These products are not distributed with LUMA.
- **Discord** is an optional integration implemented using its documented local RPC/IPC protocol. Discord's SDK/library code is not bundled. A registered application and the user's running desktop Discord client are required. https://discord.com/developers/docs/topics/rpc
- **AudD** is an optional external recognition service requiring the user's own API token. A short audio sample is sent only when audio recognition is used. Provider terms and quotas apply. https://docs.audd.io/
- **Radio streams** belong to their respective broadcasters. Station names are used to identify public streams; they do not imply endorsement or permission to redistribute music. The catalog includes links to station websites. LUMA's MIT license does not grant rights to station content, trademarks or recordings. Streams can change, contain advertisements or be region restricted. The app is intended for personal listening; public playback/rebroadcasting requires the relevant rights.

The banner is original AI-assisted project artwork. Documentation screenshots are captures of LUMA's actual interface. Any fictional collection data used in screenshots is marked as demo data.
