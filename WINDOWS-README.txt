LUMA v1.2.1

Українська інструкція: https://github.com/ThunderBoldX/LUMA#readme
English instructions: https://github.com/ThunderBoldX/LUMA/blob/main/README.en.md

1. Встановіть Node.js 22.13+ із https://nodejs.org/.
2. Розпакуйте всю папку та запустіть LUMA.exe. Рекомендований Microsoft Edge.
3. Завершення роботи: правий клік на значку LUMA у системному треї → Зупинити та вийти.

Колекція і налаштування зберігаються у папці data: не видаляйте її під час оновлення.
AudD потребує власного API-ключа. Discord Rich Presence потребує Application ID та зображення luma в Developer Portal. Файл LUMA-Discord.png міститься поруч із програмою.
Node.js не входить до архіву. Програма не має цифрового підпису. Радіопотоки потребують інтернету; станції можуть бути недоступні у вашому регіоні.
